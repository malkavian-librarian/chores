# Agent Instructions

This repo builds the Household Chores app. Before doing any work, pull context from these docs — don't guess at product behavior, architecture, or process:

- **`_docs/process.md`** — how work is tracked and how to pick up a task: tasks live as GitHub issues, how to read/close against acceptance criteria, commit conventions, and the full map of `_docs/` files. Read this first.
- **`_docs/tasks.md`** — the original task backlog the GitHub issues were generated from. Superseded by the issues themselves for current status, but useful for the full list/ordering of planned work.
- **`_docs/plan.md`** — the product spec. Read this to understand what the app should *do*, section by section (chore model, household view, creating & completing chores, recurrence, categories, navigation & settings).
- **`_docs/arch.md`** — the architecture reference. Read this to understand *how it's built*: stack choices (Django + HTMX + Postgres, deployed on Railway), app layout, data model, coding standards, and deployment notes.

Work one GitHub issue at a time. See `_docs/process.md` for the full workflow.
